Política de Privacidade

Última atualização: 18 de novembro de 2026

Esta política explica como o @mail acessa e trata dados quando você conecta uma conta Google. O @mail reúne e-mail e Google Chat em uma interface para você acompanhar suas conversas.

Dados acessados

Com sua autorização, o @mail recebe dados básicos do perfil Google, como nome e endereço de e-mail, e acessa mensagens, remetentes, assuntos, horários, marcadores e informações de conversas do Gmail. O app também lê espaços e mensagens do Google Chat. Os escopos do Gmail permitem marcar mensagens como lidas e enviar e-mails quando você solicita essas ações; o acesso ao Chat é somente leitura.

Como os dados são usados

Os dados são usados para autenticar sua conta, apresentar e organizar conversas nos contextos escolhidos por você e executar ações que você inicia, como marcar uma mensagem como lida ou enviar uma resposta. O conteúdo de e-mails e chats é buscado do Google para exibição no app; a versão atual não grava o conteúdo das mensagens no banco de dados do @mail.

Armazenamento e segurança

O backend mantém dados de conta necessários para sincronização e autenticação. Tokens de atualização do Google são criptografados antes de serem armazenados; identificadores de sessão são armazenados como hashes. A sessão web também usa armazenamento local do navegador. O @mail transmite dados por HTTPS e restringe o acesso às informações à sua sessão autenticada.

Compartilhamento

O @mail não vende dados Google nem os usa para publicidade. Os dados são enviados ao Google para autenticação, leitura e ações solicitadas por você. Provedores de infraestrutura que hospedam o app e seu backend podem processar dados estritamente para operar o serviço. O @mail não transfere dados Google para terceiros para finalidades independentes.

Retenção e exclusão

Dados de conta e credenciais são mantidos enquanto necessários para fornecer o serviço. Você pode revogar o acesso do @mail nas configurações de segurança da sua Conta Google. Para solicitar a exclusão de dados associados à sua conta no backend, escreva para maiolinidashora@gmail.com.

Política de dados do Google

O uso e a transferência pelo @mail de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Contato

Para dúvidas ou solicitações relacionadas à privacidade, contate maiolinidashora@gmail.com.
